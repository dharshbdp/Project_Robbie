# Product

## Register

product

## Users

Project Robbie's developers and its local user, working with their computer,
workspace, and custom language model from a desktop application.

## Product Purpose

Robbie Studio connects chat, computer inspection, research, memory, and a code
scratchpad to the existing Python implementation. Its primary workflow is asking
Robbie questions and inspecting the results without leaving the workspace.

## Brand Personality

Personal, direct, helpful: the assistant identity documented in the project README.

## Anti-references

Preserve the existing monochromatic desktop tool and its navigation. Avoid sample
data presented as live results, invented model status, or a new visual identity
introduced as part of backend integration.

## Design Principles

- Connect controls to actual backend behavior.
- Clearly distinguish loading, connected, unavailable, and preview states.
- Report the checkpoint and runtime actually in use.
- Preserve user work and separate conversation reset from persistent memory.

## Accessibility & Inclusion

Preserve the existing keyboard controls and dark/light themes. Connection status
must use readable text as well as visual indicators. No additional user-specific
accessibility requirements have been established.
